# Internal notes

Working artifacts, kept for their history — not documentation and not an authority.
Paths and decisions inside them may be out of date.

- `plans/` — what is being built, and `_followups.md`, the ideas deferred until a real
  need for them shows up.

There is no `design.md` here: this host's design *is* its rules, and they live in
[`AGENTS.md`](../../AGENTS.md), kept true by the code and the tests beside them.

The documentation is [`docs/`](../) — `usage.md`, `safety.md`, `config.md`,
`plugins.md` — and code comments cite it and `AGENTS.md`, never these notes.
